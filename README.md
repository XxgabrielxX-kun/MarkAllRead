MarkAllRead clears all your unread badges at once, across every server and, optionally, your DMs and group chats.

Features:

Right-click any server → “Marcar TUDO como lido” to mark everything as read;

Hotkey: standard Ctrl + Shift + L, but you can customize the shortcut;

A button in the plugin settings;

Optional: include or exclude DMs and group chats;

Option to turn the hotkey on or off;

Sends requests in batches to avoid rate limits.

How to use:

Install and enable the plugin;

Right-click a server and choose the option, press Ctrl + Alt + R, or click the button in the plugin settings.

Notes:

Very active channels can receive new messages while the plugin is running, so a few of them may show up as unread again right away. That is normal Discord behavior.

Discord updates its internals often. If the plugin stops working after an update, please open an issue.

MarkAllRead limpa todas as notificações não lidas de uma vez, em todos os servidores e, se você quiser, também nas DMs e grupos.

Recursos:

Botão direito em qualquer servidor → “Marcar TUDO como lido”;

Atalho padrão é Ctrl + Shift + L, mas você pode escolher o atalho;

Botão nas configurações do plugin;

Opção de incluir ou não as DMs e grupos;

Opção de ligar ou desligar o atalho;

Envia os pedidos em lotes para não bater no limite de requisições.

Observação: canais muito movimentados podem receber mensagens novas enquanto o plugin roda, então alguns podem voltar a aparecer como não lidos logo em seguida. Isso é normal no Discord.
